# Green Goodies

Application e-commerce développée dans le cadre de ma formation OpenClassrooms.

Le projet consiste à concevoir une boutique en ligne permettant de vendre des produits écologiques.

## Fonctionnalités

* catalogue de produits
* gestion des commandes
* gestion des utilisateurs
* interface d'administration

## Technologies

* PHP
* Symfony
* Twig
* Doctrine
* MySQL
* Bootstrap

## Objectif pédagogique

Mettre en pratique :

* architecture MVC
* gestion d'un catalogue produit
* base de données relationnelle
* développement backend Symfony
